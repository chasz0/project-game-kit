How All 12 Modules Are Implemented

Every system in this game is powered directly by the standalone modules in core/ and gameplay/.

Vec2 (Vector Math)

core/vec2.js

Purpose: Handles player movement normalization, aiming direction vectors, and fast squared-distance checks for XP gem magnetism without triggering square roots.

// Normalize movement input and scale by speed
moveDir.normalize().mult(player.stats.get('speed') * (dt / 1000));
player.pos.add(moveDir);

// Aim vector from player to world mouse
Vec2.sub(worldMouse, player.pos, aimDir).normalize();

EventEmitter (Pub/Sub Bus)

core/events.js

Purpose: Decouples combat resolution from scoring, item drops, floating damage text, screen shake, and level-up transitions.

events.on('enemyKilled', ({ enemy }) => {
  kills++;
  score += enemy.scoreValue;
  activeGems.push(gemPool.get(enemy.x, enemy.y, enemy.xpValue));
  if (rng.next() < 0.09) spawnDisposablePickup(enemy.x, enemy.y);
});

GameLoop (Fixed Timestep)

core/loop.js

Purpose: Runs physics, timers, and AI at a fixed 60Hz (16.67ms step) regardless of monitor refresh rate, and tracks live FPS.

const loop = new GameLoop(
  (dt) => {
    fsm.update(dt);
    input.update();
  },
  () => render(),
  60
);
loop.start();

InputManager (Action Mapping)

core/input.js

Purpose: Binds keys and mouse buttons to named actions, tracks single-frame presses (isPressed) for Dash/Pause, and computes canvas-relative mouse coordinates.

const input = new InputManager(canvas);
input.bind('dash', ['ShiftLeft', 'ShiftRight']);
input.bind('pause', ['KeyP', 'Tab', 'Escape']);

if (input.isPressed('dash') && dashReady) { /* trigger dash */ }

TimerManager (Delta-Time Timers)

core/timer.js

Purpose: Drives repeating wave spawners (every), weapon fire-rate delays, dash cooldown progress bars, and temporary 10s ground buff durations. Freezes automatically when paused.

// Repeating wave spawner
timer.every(3200, () => spawnWaveBatch());

// Dash cooldown with progress callback for HUD bar
timer.add(1800, () => { dashReady = true; }, (p) => { dashCooldownRatio = 1 - p; });

core/random.js

Purpose: Ensures obstacle layouts, enemy wave compositions, item drops, and level-up upgrade cards are 100% reproducible when replaying the same seed.

const rng = new Random(seedInput.value);
const w = rng.int(75, 160);
const angle = rng.range(0, Math.PI * 2);
const itemType = PICKUP_TYPES[rng.choice(keys)];

Pool (Object Pooling)

gameplay/pool.js

Purpose: Recycles bullets, enemies, XP gems, ground pickups, particles, and floating damage text to prevent garbage collection stutter during heavy waves.

const textPool = new Pool({
  create: () => ({ x: 0, y: 0, vy: -45, text: '', color: '#fff', life: 0, maxLife: 550 }),
  init: (t, x, y, text, color, maxLife = 550) => {
    t.x = x; t.y = y; t.text = text; t.color = color; t.life = 0; t.maxLife = maxLife;
  },
  size: 60, maxSize: 300
});

SpatialHash (2D Broad-Phase Grid)

gameplay/spatialHash.js

Purpose: Queries only nearby enemies within a cell radius for bullet hits, enemy-to-enemy flock separation, and Bomb AoE blasts in 0 allocations.

// Only check enemies in cells overlapping the bullet
grid.queryRadius(b.x, b.y, b.r + 24, queryScratch);
for (let j = 0; j < queryScratch.length; j++) {
  const e = queryScratch[j];
  if (collision.circleCircle(b, e)) { /* narrow-phase hit */ }
}

collision (Overlap & Manifolds)

gameplay/collision.js

Purpose: Resolves narrow-phase hits and computes penetration depth + normal vectors (nx, ny, depth) to push overlapping enemies apart and eject entities from walls.

const hit = collision.circleCircleInfo(e, other, manifold);
if (hit) {
  e.x += hit.nx * hit.depth * 0.5;
  e.y += hit.ny * hit.depth * 0.5;
}

Feature-by-Feature Implementation

How multiple modules combine to build specific gameplay mechanics.

Floating Combat Text

Pool + Camera

How it works: When a bullet hits an enemy or the player collects a pickup, a text object is pulled from textPool at the entity's world coordinates. During render() while camera.apply(ctx) is active, it rises and fades out before returning to the pool.

const spawnFloatingText = (x, y, text, color = '#fff', duration = 550) => {
  activeTexts.push(textPool.get(x + rng.range(-8, 8), y - 10, text, color, duration));
};

// On bullet hit:
spawnFloatingText(e.x, e.y - e.r, `-${Math.round(b.damage)}`, '#ffffff');

Disposable Ground Items & Timed Buffs

Pool + Stats + TimerManager

How it works: Ground items are pooled in pickupPool. Timed buffs (Speed Boost, Rapid Fire) register a modifier on player.stats and start a timer.add() tween that updates the HUD bar and removes the modifier on completion. Picking up a duplicate refreshes the timer.

const applyTemporaryBuff = (type) => {
  if (activeTempBuffs.has(type.id)) timer.cancel(activeTempBuffs.get(type.id).timerRef);
  const modId = `temp_${type.id}`;
  player.stats.addModifier(modId, type.stat, type.modType, type.val);

  const timerRef = timer.add(
    type.duration,
    () => player.stats.removeModifier(modId),
    (progress) => { state.remainingMs = type.duration * (1 - progress); }
  );
};

Live Map Regeneration Mid-Run

Random + collision + SpatialHash

How it works: Pressing G generates a new set of obstacles from the seeded RNG, then runs collision.circleBoxInfo() across the player, active enemies, and pickups to immediately push any trapped entity outside the new walls and updates the SpatialHash.

for (let i = 0; i < activeEnemies.length; i++) {
  const e = activeEnemies[i];
  for (let j = 0; j < obstacles.length; j++) {
    const hit = collision.circleBoxInfo(e, obstacles[j], manifold);
    if (hit) { e.x += hit.nx * hit.depth; e.y += hit.ny * hit.depth; }
  }
  grid.update(e);
}

Pause & Character Sheet Inspector

StateMachine + Stats + TimerManager

How it works: Switching fsm.change('paused') stops playing.update(dt) from running. Because timer.update(dt) is only called inside the playing state, all wave spawners, dash cooldowns, and 10-second buffs freeze automatically while you inspect player.stats.

fsm.add('paused', {
  enter: () => renderCharacterSheetOverlay(),
  update: () => {
    if (input.isPressed('pause')) fsm.change('playing');
  }
});
