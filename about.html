Architecture & Conventions

Built for high-entity swarm games and portable reuse across 2D web projects.

Core Design Rules

  • Zero Cross-Module Imports: Every file in core/ and gameplay/ stands completely alone. You can copy a single file into a game jam project or import the entire kit from index.js.
  • Zero-Allocation Hot Paths: High-frequency methods like SpatialHash.query() and collision.circleCircleInfo() accept reusable output structures so 60Hz updates do not trigger garbage collection spikes.
  • Class + Singleton Exports: Stateful managers (EventEmitter, InputManager, TimerManager, Random) export both their class and a convenience singleton.
  • Deterministic Simulation: Physics runs inside a fixed-timestep accumulator (GameLoop), delays run on frame delta time (TimerManager), and randomness runs through a seeded PRNG (Random).

Coordinate & Shape Conventions

  • Circles & Points: Center-based { x, y, r } or { x, y }.
  • Bounding Boxes: Top-left-based { x, y, w, h }.
  • SpatialHash Clients: Supports both center-based circles ({ x, y, r }) and top-left boxes ({ x, y, w, h }) automatically without mutating your entity objects.

Quick Start (Front-Door Import)

import {
  Vec2, events, GameLoop, input, timer, Random,
  Pool, SpatialHash, collision, Stats, StateMachine, Camera
} from './index.js';

const rng = new Random('seed-123');
const grid = new SpatialHash(64);
const cam = new Camera(800, 600);

const loop = new GameLoop(
  (dt) => {
    timer.update(dt);
    cam.update(dt);
    input.update();
  },
  (alpha) => {
    // render frame
  }
);

loop.start();
